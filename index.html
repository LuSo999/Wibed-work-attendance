Chybí konfigurace Firebase

Aplikace potřebuje připojení k vašemu Firebase projektu. Doplňte údaje do souboru js/firebase-config.js.

  1. Otevřete Firebase Console a vyberte projekt.
  2. ⚙ Project settings → General → Your apps – přidejte Web app (</>), pokud ještě není.
  3. V části SDK setup and configuration zvolte Config a zkopírujte hodnoty.
  4. Nahraďte jimi placeholdery YOUR_… v js/firebase-config.js, commitněte a obnovte stránku.

Kompletní postup (Authentication, Firestore, pravidla, domény) najdete v README.md.
